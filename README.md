# عجلة الحظ 🎡 | Wheel of Fortune

لعبة عجلة حظ تفاعلية بألوان هوية متجر **pgstor.com** — أدخل الأسماء بالعربية، أدر العجلة، وأعلن الفائز مع تصفيق ومفرقعات.

Interactive wheel of fortune themed with the **pgstor.com** brand colors. Enter Arabic names, spin the wheel, and celebrate the winner with applause and confetti.

## المميزات | Features

- 🎡 عجلة حظ حديثة بحلقة LED معدنية وهوالة متوهجة
- 📝 إدخال الأسماء دفعة واحدة (كل اسم في سطر أو مفصول بفاصلة)
- 💾 حفظ الأسماء محليًا في المتصفح (localStorage)
- 🏆 إعلان الفائز في نافذة احتفالية بوسط الشاشة
- 👏 صوت تصفيق حقيقي + 🎊 مفرقعات عند الفوز
- 🔊 صوت عجلة كازينو أثناء الدوران + صوت خسارة كوميدي
- ❌ وضع الإقصاء: كل اسم يظهر يُحذف حتى يبقى آخر اسم هو الفائز
- 🖼️ شعار المتجر المدمج + رابط pgstor.com

## الاستخدام | Usage

1. افتح [الموقع المباشر](https://wheel-nine-kohl.vercel.app/) أو افتح `index.html` في المتصفح
2. أدخل الأسماء ثم اضغط «إضافة الكل»
3. اضغط «ابدأ السحب» واستمتع!

## الأصوات | Sound

جميع الأصوات مدمجة داخل الملف نفسه (base64) — لا حاجة لملفات خارجية أو إنترنت.

## النشر | Deploy

مستضاف على [Vercel](https://vercel.com) من فرع `main` — النشر التلقائي من GitHub.
